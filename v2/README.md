## Scope

This version is contained entirely inside `v2/`. Version 1 retains its layout, stylesheet and broader work samples. The November 20 feedback revision updates the BEES and SupplyBistro content in both designs, adds companion outreach documentation and updates the reporting examples in their existing project repositories. Earlier site files remain recoverable through Git history. The GitHub profile and pinned projects are unchanged.

The homepage features reporting, vendor outreach and nonprofit strategy, with search evaluation and athletics research available as additional cases. Every case has a readable HTML narrative and supporting GitHub links. Leadership, intake and tutoring samples use the same alternate visual style.

Historical responsibilities remain separate from the independent 2026 work. All synthetic scenario results retain their provenance. The new site and example code were prepared with AI assistance.

## Design decisions

The opening is shorter, project titles describe decisions, and inline previews explain why an artifact matters. Individual case pages provide depth without placing every detail on the landing page. The research notes separate empirical work, official guidance, practitioner opinion and self-selected forum accounts; they also document TikTok access limits and conflicting views on PM portfolios.

The navy/cobalt palette is an alternate design choice, not a claim that a particular color improves hiring outcomes. No testimonial, personal outcome metric or professional headshot was invented. Contact uses the user's existing LinkedIn profile. No unverified resume download was added.

## Implementation

Static HTML and CSS run directly on GitHub Pages. The only JavaScript fits the two comparison frames to matching desktop, tablet and phone widths. Content remains available without JavaScript through the normal links. There are no external fonts, dependencies, trackers or contact-form services.

`noindex,follow` marks the alternate pages as a comparison candidate while preserving normal navigation. It is not an access-control mechanism; these pages are public.

## Review checklist

Check that the intended role is evident, original contributions are distinguishable from current examples, each case communicates a consequential decision, artifacts are inspectable, contact links work, and ordinary page text reflows at narrow widths. The comparison page is a design review tool, not an A/B experiment with hiring outcomes.
