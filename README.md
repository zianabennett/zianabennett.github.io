# Ziana Bennett portfolio

A lightweight, accessible portfolio website connecting four case-study repositories with my background in product and business operations.

## Site

[Open the portfolio](https://zianabennett.github.io/)

The page is a static HTML document with local CSS, responsive layouts, and no tracking or external font dependencies. Project cards link to the complete GitHub case studies. Each project distinguishes historical work from new portfolio extensions.

## Files

- `index.html` contains the page content and semantic structure.
- `styles.css` controls the responsive layout and visual design.
- `.nojekyll` keeps the site in GitHub Pages' plain static-file workflow.

## Publishing

Configure GitHub Pages to deploy from `main` and `/(root)`. Changes to the published branch update the site after GitHub's deployment completes.
