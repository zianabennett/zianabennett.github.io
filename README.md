# Ziana Bennett portfolio website

A responsive, buildless portfolio for product and business operations work.

**Live site:** https://zianabennett.github.io/

## What visitors can explore

- Five case studies with original role context and separately labeled new portfolio work samples.
- Report and research previews calculated from the corresponding project repositories.
- A visual career timeline and an Experience & Leadership section covering ALSO, Fight for Families, Cavalier Connect, and StarHill Pathways.
- Three new illustrative work samples on event leadership, administrative document handoffs, and tutoring session design.
- An About section connecting professional experience with the kind of work Ziana wants to do.

## Structure

- `index.html` contains the homepage and its accessible data previews.
- `styles.css` provides the shared responsive design, focus styles, reduced-motion support, and print rules.
- `assets/` contains the ZB monogram and exported source charts.
- `samples/` contains standalone illustrative process and learning-design examples.
- `.nojekyll` enables direct static-file hosting.

There are no build dependencies, tracking scripts, or external font requests. Native HTML and CSS provide the visualizations and page navigation.

## Data and claims

Historical role context follows the available personal background. New work samples and their synthetic data are labeled. Displayed quantitative reporting values come from the SupplyBistro results, event-operation figures come from the BEES results, search percentages come from the eight-query demonstration, and research counts come from the source-coded eight-institution corpus. They are not presented as historical employer outcomes.

The nonprofit strategy project uses a fictional organization and explicit planning assumptions. The role context refers to the 2024 PwC/Mercy Education Project externship, not to delivery of the newly created model.

## Publishing

GitHub Pages serves `main` from the repository root. Keep linked asset names and sample filenames consistent when editing. The public links use the `zianabennett` GitHub account.
